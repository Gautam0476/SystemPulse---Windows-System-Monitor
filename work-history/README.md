# Work History Folder

Purpose: Is folder ka kaam project ki running history, decisions, fixes, commands aur next-Codex handoff ko store karna hai.

Use this folder when:

- Context limit over ho jaye
- User dusri ID se login kare
- New Codex ko project samjhana ho
- Previous work, bugs, fixes, commands ya feature status check karna ho

Recommended reading order for a new Codex:

1. `HANDOFF_FOR_NEXT_CODEX.md`
2. `CONVERSATION_LOG.md`
3. `../WORK_HISTORY.md`

Important note:

Future conversation automatic background mein save nahi ho sakti. Jab Codex active response/work kare, tab relevant updates manually is folder mein add karne chahiye.
