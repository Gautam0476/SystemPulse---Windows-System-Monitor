# Differentiating Feature Ideas

Purpose: concise list of features that can make this project clearly different from Windows Task Manager.

## Best Next Features

1. Startup change monitor
   - Track newly added startup entries, changed commands, and suspicious locations.

2. Suspicious process scoring
   - Explainable score using path, usage, unknown publisher, startup changes, and local history.
   - Do not position this as antivirus replacement.

3. Process notes and labels
   - Let user mark processes as trusted, unknown, browser, editor, check later, etc.

4. Weekly performance report
   - Top CPU/RAM consumers, most frequent apps, startup changes, and recommendations.

5. One-click modes
   - Gaming, Study, or Work mode that applies rules/profiles to background apps.

## Already Implemented Differentiators

- Automation rules with alert/kill actions.
- Smart desktop alerts for automation messages and sustained high CPU/RAM.
- Process history and summaries.
- Secure browser/mobile dashboard.
- Visualization tab with CPU/GPU/memory/battery/process pressure score.

## Recommended Priority

Build next in this order:

1. Startup change monitor.
2. Suspicious process scoring.
3. Process notes and labels.

These reuse the existing process monitor, rules, startup manager, and history store, so they are practical and interview-friendly.
