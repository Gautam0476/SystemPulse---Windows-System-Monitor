# Update Protocol

When the user asks for changes, fixes, searches, or explanations, update this folder after meaningful work.

## What To Save

Save:

- User request summary
- Important assistant response summary
- Files changed
- Commands run
- Build/test results
- Bugs found
- Fixes applied
- Current app status
- Any blocker or limitation

Do not save:

- Every tiny thinking step
- Large command output unless it matters
- Secrets, tokens, private credentials

## Files To Update

Usually update:

- `CONVERSATION_LOG.md` for chronological history
- `HANDOFF_FOR_NEXT_CODEX.md` if project state or important instructions changed
- `../WORK_HISTORY.md` for broader project feature history

## Style

Write so a fresh Codex can continue without asking the user to repeat context.

Use:

- Clear headings
- Exact file names
- Exact commands
- Short status notes
- Hinglish context where useful
